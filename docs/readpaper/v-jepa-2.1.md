# V-JEPA 2.1：让视频预测表征同时保留局部结构与全局语义

这篇论文最值得抓住的主线是：

> **一个视频特征可以很好地支持动作识别，却不一定能清楚表达每个位置上的物体、边界和几何结构。V-JEPA 2.1 重新设计训练监督，让视频预测表征具备更好的局部可读性，同时尽量保留全局理解能力。**

它对你正在考虑的 JEPA 视频重拍方向有直接的表征层意义。不过，需要把“学到了更好的密集视频特征”与“已经能够根据目标相机预测新视角世界状态”分开讨论。

---

## 一、Introduction：为什么 V-JEPA 2 的特征还需要改进？

### 1.1 全局理解好，不代表每个 patch 的特征都好

先用一个简单例子区分两类能力。

对于“一个人正在把杯子放到桌上”这段视频，动作识别需要知道事件整体是什么。模型可以综合人物姿态、手部运动、杯子位置变化，最后给出一个类别。

但是，深度估计、分割、跟踪以及你关心的视频重拍，还需要回答更细的问题：**哪一组特征对应杯子边缘？手与杯子的接触发生在哪里？这个位置在下一帧对应哪个位置？**

这两类任务对表征的要求不同。可以用两个概念性条件表示：

- 全局信息可读：从整个特征集合中，能够恢复视频级语义。
- 局部信息可读：从对应位置附近的特征中，能够恢复空间结构与局部状态。

前者成立，并不能推出后者成立。例如，一个网络可以把非常有用的全局信息分散编码在所有 token 中，使分类头很好用，但让简单的逐位置预测头难以解码局部边界。

论文对 V-JEPA 2 的观察正是：**动作理解较强，但密集特征中的局部结构不容易被简单预测头提取出来。**作者用 PCA 可视化和冻结编码器的密集任务评估共同支持这一观察。[arXiv](https://arxiv.org/html/2603.14482v3)

### 1.2 作者提出了什么机制假设？

作者把问题指向原始 JEPA 训练中的一个不对称性：

**模型用可见区域的 token 去预测被遮挡区域，但损失只计算在被遮挡位置。**

因此，可见 token 的任务主要是“为缺失区域提供有用信息”。它们没有同等强度的要求，必须保留自己所在位置的局部信息。作者认为，这会让部分可见 token 更倾向于承担全局信息汇聚的角色。[arXiv](https://arxiv.org/html/2603.14482v3)

这里必须精确一点：

**可见 token 并不是没有梯度。它们缺少的是对应自身位置的直接预测监督。**

这一点是理解全文的基础。

## 二、Section 2.1：先把原始 V-JEPA 的训练过程讲清楚

### 2.1 输入、编码器和预测器分别做什么？

记完整视频为 $y$，删除部分 patch 后的输入为 $x$。可见位置集合为 $C$，被遮挡位置集合为 $M$。

训练有两条分支：

**在线分支**处理 $x$。在线编码器 $E_\theta$ 只接收可见 token，得到上下文特征；随后加入带有缺失位置编码的 mask token，交给预测器 $P_\phi$。

**目标分支**处理完整输入 $y$。目标编码器 $E_{\bar\theta}$ 产生所有位置的目标特征。目标分支不通过损失反向传播更新，其参数通过在线编码器的指数移动平均更新。官方训练代码明确实现了完整输入的无梯度 teacher 前向和随后的 EMA 更新。

为了简化表达，记预测器在位置 $i$ 的输出为 $\hat z_i$，目标编码器的对应特征为 $z_i^{\mathrm{teacher}}$。

原始目标是：

$$
\mathcal L_{\mathrm{predict}}
=
\frac{1}{|M|}
\sum_{i\in M}
\left\|
P_\phi(E_\theta(x),\Delta_y)_i
-
\operatorname{sg}\!\left(E_{\bar\theta}(y)_i\right)
\right\|_1 .
$$

其中，$\Delta_y$ 表示缺失位置对应的 mask token，$\operatorname{sg}$ 表示停止梯度。预测目标是**特征向量**，不要求恢复 RGB 像素。[arXiv](https://arxiv.org/html/2603.14482v3)

### 2.2 为什么这种目标不一定产生好的局部特征？

下面是对优化机制的解释，而不是论文额外给出的定理。

设一个可见位置的编码器输出为 $h_j$，其中 $j\in C$。它接收的梯度可以概念性地写成：

$$
\frac{\partial\mathcal L_{\mathrm{predict}}}{\partial h_j}
=
\sum_{i\in M}
\left(\frac{\partial\hat z_i}{\partial h_j}\right)^\top
\frac{\partial\ell_i}{\partial\hat z_i}.
$$

这个梯度在要求 $h_j$ 帮助预测缺失位置 $i$，但没有单独要求：“$h_j$ 必须让位置 $j$ 的局部状态容易恢复。”

例如，当缺失区域是人的手部时，模型可能需要汇总身体姿态、动作阶段和物体关系。让可见 token 存储这些全局信息，是一种合理的优化结果；但这种编码方式未必最适合后续的逐像素分割或深度回归。

所以，这篇论文真正关注的是：

**预测目标的设计，如何改变信息在 token 之间的组织方式。**

不是只看表征“有没有信息”，还要看信息是否以适合下游任务读取的方式存在。

## 三、Section 2.2–2.3.1：Dense Predictive Loss 如何改善局部结构？

### 3.1 新增可见位置的预测监督

V-JEPA 2.1 给可见位置也加上目标特征匹配：

$$
\mathcal L_{\mathrm{ctx}}
=
\frac{1}{|C|}
\sum_{i\in C}
\lambda_i
\left\|
\hat z_i
-
\operatorname{sg}\!\left(z_i^{\mathrm{teacher}}\right)
\right\|_1,
\qquad
\mathcal L_{\mathrm{dense}}
=
\mathcal L_{\mathrm{predict}}
+
\mathcal L_{\mathrm{ctx}}.
$$

从实际实现看，预测器分别输出 `z_pred` 和 `z_context`，训练代码分别提取 teacher 的被遮挡位置和可见位置，再计算两部分损失。**因此，context loss 约束的是预测器在可见位置的输出，不是直接对输入图像做重建，也不是简单地给编码器原始输出加一个恒等映射损失。**

它带来的新要求是：

“你不仅需要帮助补全其他区域，也需要让自己所在位置的目标表征能够被恢复。”

这里在线分支和 teacher 的信息条件仍然不同：在线分支看的是缺失部分内容的输入，teacher 看的是完整输入。因此，即使监督位置是可见的，也不能把这个任务直接等同于复制输入。

### 3.2 为什么不能给可见 token 一个很大的统一权重？

从优化角度看，两部分目标存在张力。

被遮挡位置的预测迫使模型利用跨位置、跨时间信息；可见位置的匹配则增加了保留局部内容的压力。假如后一项过强，网络可能优先解决较容易的可见位置匹配，降低对复杂运动和全局关系的建模需求。

这不是“局部信息不好”，而是**同一个有限容量模型如何分配学习资源**的问题。

作者因此为 context loss 设计了权重调度和距离加权。训练中逐步引入 context loss；同时，让靠近缺失区域的可见 token 获得更高权重。[arXiv](https://arxiv.org/html/2603.14482v3)

### 3.3 距离权重究竟是什么？

论文的权重形式为 $\lambda_i=\lambda/\sqrt{d_{\min}(i,M)}$。

官方 `masks_dist.py` 的实现很明确：把 token 索引还原成时间、高度、宽度三个网格坐标，计算可见 token 到所有被遮挡 token 的欧氏距离，取最小值，再开平方；损失中使用它的倒数。实现还提供了按网格分辨率调整距离尺度的选项。

因此，这个权重可以理解为：

**越靠近待补全区域，越强调周围可见特征与完整输入下目标特征的一致性。**

例如，忽略尺度修正，取 $\lambda=0.5$：最小距离为 1 时，权重为 0.5；距离为 4 时，权重为 0.25。

但这里有两个重要边界。

第一，**它不是几何置信度、深度可靠性或可见性概率。**它只利用训练 mask 在 token 网格中的位置关系。

第二，它也不是显式的邻域平滑项。损失中没有直接要求相邻两个 token 满足 $\|z_i-z_j\|$ 很小。它增加的是每个位置匹配 teacher 的压力，而不是要求所有相邻位置变得相似。

这一点对你的项目很重要：不能直接把这里的距离权重称作“几何可靠性加权”。

### 3.4 这个设计是否保证 token 被严格绑定到局部位置？

不保证。

context loss 增强了对应位置目标特征的可恢复性，但预测器仍然可以利用整段上下文。一个位置的信息仍有可能通过其他 token 补充回来。

因此，更稳妥的理解是：

**它改变了学习局部结构的激励，而没有在数学上强制每个 token 只能包含局部信息。**

是否真的改善了局部表征，需要下游实验验证。

## 四、Section 2.3.2：Deep Self-Supervision 是解决性能冲突的关键

### 4.1 为什么只加 context loss 还不够？

如果把这篇论文概括成“给所有 token 加损失”，会漏掉一个重要结论：

**单独加入 context loss 虽然改善密集预测，却明显损害全局识别。**

作者进一步采用多层自监督：让中间层和最终层共同参与 JEPA 特征预测，而不是只监督编码器最后一层。[arXiv](https://arxiv.org/html/2603.14482v3)

### 4.2 多层特征是怎样进入预测器的？

设选取四个编码器层级，得到同一个可见位置的四组特征 $h_i^{(1)},\ldots,h_i^{(4)}$。

把它们沿通道维拼接，再通过一个 MLP 压缩：

$$
u_i
=
\operatorname{MLP}
\left(
\operatorname{Concat}
\left[
h_i^{(1)},h_i^{(2)},h_i^{(3)},h_i^{(4)}
\right]
\right).
$$

得到的 $u_i$ 与 mask token 一起进入共享预测器。预测器输出则需要匹配 teacher 对应的四个层级。官方实现中，多层输入先经过通道融合 MLP；teacher 的不同层级特征分别归一化后再拼接。

这里有一个容易被流程图误导的细节：

**官方代码使用一个共享的 Transformer predictor，并不是四个独立预测器。**

具体来说，预测器有一个共享主干，最后分别通过：

- 面向被遮挡位置的输出投影；
- 面向可见位置的输出投影；

生成对应的多层 teacher 特征。四个层级被组织在输出通道中。也不应把它误读成“在预测器的四个中间深度分别挂四个损失”。

### 4.3 多层监督为什么可能同时帮助局部和全局？

下面是我对机制的理解。

只使用最终层目标时，监督目标本身的结构取决于最终层当前学成了什么。如果最终层已经较强地偏向全局语义，那么整个训练过程主要是在拟合这种信息组织方式。

加入中间层目标后，预测器必须同时恢复多个抽象层次的信息。即使不同层并不严格对应“边缘—物体—动作”的固定层级，它们也提供了比单一最终层更丰富的约束。

从优化上看，这增加了两类路径：

**多层输入路径**让预测器直接访问不同深度的上下文信息；**多层目标路径**要求模型保留能支持不同深度目标预测的信息。

所以，这个模块同时改变了“预测器看什么”和“预测器被要求预测什么”。这也意味着，论文的多层模块不能简单等同于一个额外辅助损失。

### 4.4 训练时多层监督，是否意味着推理时必须取多层特征？

不意味着。

多层自监督是预训练机制；下游任务使用哪一层，是另一个选择。论文特别关注最终层特征的密集可用性，而附录也检验了下游拼接多层特征是否仍有收益。[arXiv](https://arxiv.org/html/2603.14482v3)

对工程使用来说，这个区别很实用：

**训练时通过更丰富的监督改善最终层，可以减少下游为了恢复局部细节而额外拼接多层特征的需要。**

不过，“减少需要”比“多层特征完全没有价值”更符合实验。

## 五、Section 2.3.3–2.3.6：完整训练方案不只有两项损失

### 5.1 Multi-Modal Tokenizer 指的是图像与视频

这里的“多模态”指 **image 与 video**，不意味着预训练时同时使用文本或音频。

图像使用二维 patch embedding，视频使用三维 tubelet embedding；二者进入共享编码器，并通过模态嵌入区分。典型空间 patch 为 $16\times16$，视频 tubelet 覆盖 2 帧。官方配置中也明确区分单帧图像输入、视频输入和模态嵌入。[arXiv](https://arxiv.org/html/2603.14482v3)

为什么这不只是一个接口上的小改动？

因为“一张静态图片”和“一段观察到完全静止的场景视频”并不等价。前者没有提供时间观测，后者提供了“这段时间内没有变化”的信息。用独立 tokenizer，可以避免在输入层面把二者完全混同。

从计算上也容易理解：在 $256\times256$ 分辨率下，一张图片对应 256 个空间 token；16 帧视频采用两帧 tubelet 时，对应 2,048 个时空 token。没有必要为了处理单张图片，把它伪装成完整的视频 token 序列。

### 5.2 数据扩展：VisionMix163M

论文扩大了图像数据部分，并重新平衡图像与视频的训练分布。**VisionMix163M 中包含 142M 图像，不能把 163M 理解成视频数量。**其设计意图是让图像提供更丰富的外观和空间结构，让视频提供运动与动态信息。[arXiv](https://arxiv.org/html/2603.14482v3)

这里值得注意的是：数据扩展改变的不只有样本总量，也改变了静态信息与动态信息的来源和比例。因此，最终结果不能全部归因于损失函数。

### 5.3 主训练与高分辨率 cooldown

论文附录给出的主要训练规格如下：

| 项目 | 主训练阶段 | Cooldown 阶段 |
|---|---:|---:|
| 训练步数 | 135,000 | 12,000 |
| 视频帧数 | 16 | 64 |
| 视频分辨率 | $256\times256$ | $384\times384$ |
| 图像分辨率 | $256\times256$ | $512\times512$ |

主训练先学习表征，后续以更长视频和更高分辨率进一步调整；预训练 predictor 使用 24 层、384 维隐藏表示。[arXiv](https://arxiv.org/html/2603.14482v3)

高分辨率阶段的收益也不能只理解为“看得更清楚”。视频长度和空间 token 数量同时增加，模型看到的训练上下文也发生了变化。

### 5.4 小模型蒸馏与大模型预训练存在差别

官方发布了 1B、2B 模型，以及 80M、300M 的较小蒸馏模型。

蒸馏时，目标分支改为冻结的大模型 teacher，并且只使用最终层监督，不再沿用完整的四层深度自监督；预测器也重新训练。[arXiv](https://arxiv.org/html/2603.14482v3)

这个区别有方法论意义：

**用于建立一个强表征空间的训练方案，不一定是把这个空间迁移给小模型时最稳定的方案。**

因此，使用一个 V-JEPA 2.1 小模型，并不意味着它在训练时完整执行过大模型的所有模块。

## 六、Section 2 的消融：哪些设计真正起了作用？

### 6.1 Table 1 是全文最值得仔细读的表

下面保留三个能展示主要矛盾的指标。SSv2 越高越好，衡量动作识别；NYUv2 RMSE 越低越好，衡量深度；ADE20K mIoU 越高越好，衡量语义分割。

| 累积加入的设计 | SSv2 ↑ | NYUv2 RMSE ↓ | ADE20K mIoU ↑ |
|---|---:|---:|---:|
| V-JEPA 2 基线 | 72.8 | 0.682 | 22.2 |
| + Context loss | 62.5 | 0.474 | 33.8 |
| + 多层自监督 | 72.1 | 0.463 | 38.6 |
| + VisionMix | 72.6 | 0.418 | 40.8 |
| + 模态专用 tokenizer | 72.6 | 0.415 | 41.4 |
| + 扩大至 2B | 76.1 | 0.365 | 47.1 |
| + Cooldown | 77.7 | 0.307 | 47.9 |

数值采用论文表格；前几行是逐步修改的基线，不能与后文最终模型比较表中的不同规模结果混用。[arXiv](https://arxiv.org/html/2603.14482v3)

从这些数值，我认为可以得出四个较稳妥的判断。

**第一，context loss 确实改变了表征偏好。**ADE20K 改善的同时，SSv2 明显下降。这支持“局部可读性与全局预测能力需要平衡”的判断，而不支持“所有 token 加监督后自然全面提升”。

**第二，多层自监督是恢复平衡的关键。**它让动作识别接近原始基线，同时进一步改善密集任务。因此，把它当作普通的附加优化，会低估它在整套方法中的作用。

**第三，tokenizer 的独立数值收益相对温和。**这一行的动作识别没有变化，密集任务小幅改善。它的价值还包括正确区分输入模态和提高处理效率，但不能仅凭这张表把它描述为最大性能来源。

**第四，最终结果包含显著的数据、模型和训练阶段收益。**只实现 context loss 和多层监督，不应期待直接得到最终 2B 模型的全部性能。

### 6.2 Table 2：context 权重不是越大越好

权重实验的主要信息是：较强的可见位置监督可能损害全局任务，而且密集指标也并非随权重无限增加。逐步引入损失和距离加权能够改善折中，但没有单独消除全局性能下降。[arXiv](https://arxiv.org/html/2603.14482v3)

从实验设计角度看，这也提醒我们：**损失权重控制的是学习资源的分配，而不只是“约束强度”。**

### 6.3 这组消融还没有完全回答什么？

表格采用累积加入模块的方式，适合展示一条有效训练路径，但不等于完整的因子实验。

例如，它还没有充分拆开：

多层输入融合的收益有多少？多层目标监督的收益有多少？增大 predictor 容量的收益有多少？这些因素在不同数据规模下是否具有相同作用？

因此，我会把论文机制结论表述为：

**实验较有力地支持这套组合方案有效；各组件为何有效以及相互作用的精确分解，仍有进一步研究空间。**

## 七、Section 3：逐类理解实验，避免把所有结果读成同一个结论

### 7.1 深度与语义分割：密集特征的改善最明确

选取最终模型比较中的几个代表性指标：

| 模型 | 参数量 | NYUv2 RMSE ↓ | ADE20K mIoU ↑ | DAVIS $\mathcal J\&\mathcal F$ ↑ |
|---|---:|---:|---:|---:|
| V-JEPA 2 | 1B | 0.642 | 24.4 | 52.5 |
| V-JEPA 2.1 | 1B | 0.350 | 47.8 | 68.1 |
| V-JEPA 2.1 | 2B | 0.307 | 47.9 | 69.0 |
| DINOv3 | 7B | 0.309 | 55.9 | 71.1 |

对应深度和语义分割采用冻结表征上的预测头评估，视频分割使用特征传播协议。[arXiv](https://arxiv.org/html/2603.14482v3)

**最重要的是同为 1B 的对比。**它排除了“所有改善都只是因为从 1B 增长到 2B”这种解释。至少在这些协议下，训练方案确实让密集信息更容易被读取。

但与 DINOv3 的比较需要保持分寸。

NYUv2 上 0.307 与 0.309 非常接近；没有误差范围时，不宜放大这点差异。另一方面，ADE20K 和 DAVIS 上仍有明显差距。所以更准确的总结是：

**V-JEPA 2.1 大幅缩小了视频预测表征在密集任务上的短板，而没有全面取代强图像表征。**

另外，“深度估计效果好”在这里主要说明**深度信息容易从冻结特征中解码**。它不等于预训练模型直接输出深度，也不等于已经战胜所有端到端深度估计系统。

### 7.2 视频目标分割：它测试的是特征对应关系

视频分割实验以第一帧的真实目标掩码为起点，通过特征相似度传播到后续帧。它不是一个从零识别目标、再联合训练分割器的完整系统。[arXiv](https://arxiv.org/html/2603.14482v3)

这类测试对你的方向尤其有参考价值：如果一个物体在不同帧的特征具有更稳定的对应关系，标签传播就更容易成功。

但它仍然不能直接证明跨相机视角的一致性。**时间上的对应关系与大幅视角变化下的对应关系，是两个相关但不同的要求。**

还需注意，论文的 YouTube-VOS 实验使用自定义的数据划分协议，不应直接与官方隐藏测试集排行榜数字混为一谈。[arXiv](https://arxiv.org/html/2603.14482v3)

### 7.3 Ego4D 交互预测：比动作分类更接近局部状态预测

这个任务不仅预测未来动作，还涉及将要交互的物体位置、类别和接触时间。V-JEPA 2.1 的完整指标达到 7.71 mAP。[arXiv](https://arxiv.org/html/2603.14482v3)

这类实验比单纯的视频分类更有说服力，因为预测错误可能来自多个方面：动作判断正确，但物体位置错误；物体正确，但接触时间错误；场景语义正确，但局部状态不清楚。

不过，评估系统还训练了任务相关的注意力模块和检测头，不能把结果表述为“原始 JEPA 编码器无需训练就会预测交互”。[arXiv](https://arxiv.org/html/2603.14482v3)

我的理解是：这个结果支持**新的特征更适合作为交互预测的输入状态**，而不是证明编码器本身已经拥有完整的交互决策能力。

### 7.4 动作预测与分类：并非所有全局任务都提升

这里有一个特别重要的同规模结果：

EK100 动作预测中，V-JEPA 2 的 1B 模型为 39.7，V-JEPA 2.1 的 1B 模型为 38.4；扩大到 2B 后达到 40.8。[arXiv](https://arxiv.org/html/2603.14482v3)

因此，不能简单总结为“局部特征改善后，未来预测一定更好”。

这组结果反而揭示了全文最有研究价值的问题：

**让状态表示更细致，与让未来事件更容易预测，并不天然是同一个优化目标。**

一个模型可能更精确地保留了当前场景细节，却没有同等程度提升对未来关键变化的抽象。这也是为什么作者需要多层监督、数据平衡与容量扩展共同作用。

分类结果同样存在任务间差异，较稳妥的结论是总体保持较强全局能力，而不是每项指标都超过原模型。[arXiv](https://arxiv.org/html/2603.14482v3)

### 7.5 机器人抓取：“提高 20 个百分点”包含规划配置变化

这是阅读摘要时最容易被忽略的实验细节。

| 设置 | 规划时域 | 单次规划时间 | 抓取成功率 |
|---|---:|---:|---:|
| V-JEPA 2 | 1 | 3 秒 | 60% |
| V-JEPA 2.1，匹配规划设置 | 1 | 3 秒 | 70% |
| V-JEPA 2.1，更长规划 | 8 | 14 秒 | 80% |

论文每项技能评估 10 次。[arXiv](https://arxiv.org/html/2603.14482v3)

因此，**匹配配置下的提升是 10 个百分点；20 个百分点对应的结果还包含更长时域与更多规划计算。**

这不否定结果价值。更好的状态表征可能确实使更长规划更有效。但是，从因果归因上，需要区分：

表征替换本身的贡献，以及表征替换后配合新的规划设置得到的系统收益。

另外，这里的机器人系统经过动作条件预测器训练。“零样本部署”指迁移到新的部署环境，不意味着完全没有使用机器人交互数据。[arXiv](https://arxiv.org/html/2603.14482v3)

### 7.6 导航实验为什么出现 diffusion？

论文导航部分在 JEPA 特征上另外训练了条件扩散 Transformer，并改变了预测参数化与采样方式。因此，这一节确实涉及 diffusion，但它不是 V-JEPA 2.1 基础预训练目标。[arXiv](https://arxiv.org/html/2603.14482v3)

理解时可以拆成两层：

**表征模型**决定状态如何编码；**动力学模型**决定给定状态和动作后，未来状态如何变化。

二者可以采用不同建模方式。使用 JEPA 表征，并不要求后续动力学预测器也必须采用同一种训练目标。

论文报告的导航规划加速属于这一完整配置的结果，不能直接外推成“把视频生成器的 VAE 换成 JEPA，生成就会加速十倍”。

### 7.7 视频问答和 PCA：补充证据，不是核心证明

视频问答还需要与语言模型对齐；各项评测有升有降，因此它提供的是表征迁移能力的补充证据。PCA 图则有助于观察特征结构，但不能单独证明精确几何、物体身份保持或因果理解。[arXiv](https://arxiv.org/html/2603.14482v3)

我会把证据强度排序为：**任务指标和受控消融优先，特征可视化辅助解释。**

## 八、附录与官方代码：几个影响理解和复现的细节

### 8.1 多层监督没有让中间层特征彻底失去价值

附录对“只用最终层”和“拼接多层”的比较表明，多层自监督改善了最终层特征，但部分任务继续使用多层特征仍有额外收益。[arXiv](https://arxiv.org/html/2603.14482v3)

因此，实际迁移时可以把最终层视为更强的默认输入，而不应预先认定所有层级融合都没有必要。

### 8.2 基础预训练并不是严格的动作条件因果建模

官方预训练配置明确设置编码器与 predictor 为非因果模式，且不包含机器人动作输入。

这意味着，基础训练主要是在视频上下文中学习缺失表征预测。它能够为未来预测提供有价值的初始化，但不能仅凭这个训练形式，就认定模型已经学习了可任意干预的状态转移函数。

这也是区分下面三件事的理由：

**表征学习、缺失内容预测、动作干预后的未来预测。**

它们可以共享基础模型，但对应不同的训练条件与实验要求。

### 8.3 公开示例配置不等于论文最终完整配方

我检查了官方 `configs/train_2_1/vitG16/pretrain-256px-16f.yaml`。其中图像源示例仍写为 ImageNet 路径，视频源与采样权重也与论文最终混合数据设置不同；图像 context 权重示例为 0.5，而论文附录报告为 0.7。[arXiv](https://arxiv.org/html/2603.14482v3)

所以，复现时应该区分：

**模型代码实现了什么、示例配置默认运行什么、论文最终实验实际采用什么。**

代码公开并不自动意味着下载示例配置后，就能复现最终发布模型的全部训练条件。

## 九、这篇论文的新贡献和局限，应该怎样定位？

### 9.1 我认为最核心的贡献

它把一个容易被忽略的问题具体化了：

**预测表征的有效性，取决于信息如何被组织在各个位置和层级中。**

已有的 masked latent prediction、EMA teacher、ViT 等组件构成基础。V-JEPA 2.1 的方法重点，是通过可见位置监督和多层预测目标重新安排学习压力，再配合图像—视频输入与数据训练方案，把密集特征的短板补起来。官方代码中的两路位置输出、多层融合和距离加权，也清楚体现了这一设计。

### 9.2 仍然需要保留的三类限制

**第一，机制解释的证据边界。**消融证明了训练目标与下游表现之间的关系，但“可见 token 变成全局汇聚器”仍是一种机制解释。更完整的验证还可以直接分析 token 的空间敏感性、信息分布和不同层级的局部可恢复性。

**第二，世界模型能力的边界。**局部特征更好，有利于状态估计，但还不足以证明模型能够区分相机运动与物体运动、理解遮挡后的状态、进行长时因果推演。这些要求需要对应的干预、跨视角和长时评估。

**第三，系统收益的归因边界。**机器人、导航和问答结果包含后续模型、训练与推理配置。它们证明这些特征具有使用价值，但不能把全部系统收益直接归因于某一个预训练损失。

这些限制不削弱论文的主要结论，反而帮助明确它真正解决了哪一层问题。

## 十、对你的 Video Reshooting / JEPA 方向有什么实际意义？

下面是结合你项目的分析，不是论文已经完成的实验。

### 10.1 它更适合充当“局部状态表征”，而不是直接充当生成结果

你的视频重拍目标要求保持同一动态事件，同时改变相机。这里需要的表征不能只有“这段视频讲了什么”，还要尽量保留物体的位置关系、局部状态、运动阶段与跨帧对应。

因此，我认为 V-JEPA 2.1 对你的价值主要在于：

**它提供了一个比原始 V-JEPA 2 更值得测试的密集视频 teacher 或条件编码器。**

但论文的输入接口没有目标相机条件，预训练目标也不是跨相机预测，所以不能直接假设它已经解决了视角变换。

### 10.2 JEPA 表征与生成器 latent 不应直接等同

从建模需求来看，重拍系统至少需要区分两种信息：

一类信息适合判断“物体是什么、动作是否一致、结构是否合理”；另一类信息需要支持“源人物纹理、衣服细节、背景外观怎样还原”。

前者可以允许一定外观不变性；后者却需要保留足够的可重建细节。

所以，即使 JEPA 特征很适合语义与动态约束，也不能据此推断它天然适合替代一个经过重建训练的生成 latent。你仍然需要检验外观信息是否被保留、能否解码，以及与生成器的接口如何对齐。

### 10.3 真正的跨视角 JEPA，还需要额外定义预测任务

一个与你的目标更匹配的概念形式可以是：

$$
\widehat Z^{\mathrm{target}}
=
F_\psi\!\left(
E(V^{\mathrm{source}}),
G,
C^{\mathrm{source}},
C^{\mathrm{target}}
\right),
\qquad
Z^{\mathrm{target}}
=
\operatorname{sg}\!\left(E(V^{\mathrm{target}})\right).
$$

这里，$E$ 可以采用冻结的 V-JEPA 2.1；$G$ 是几何信息，$C$ 是相机条件，$F_\psi$ 才是你需要额外研究的跨视角预测器。

这个写法立即暴露出真正需要解决的问题：目标特征怎样与源场景对齐？新出现的区域从哪里获得监督？目标视角只用于 teacher 时，如何防止信息泄漏？运动与相机变化怎样分离？

**V-JEPA 2.1 改善了候选目标表征的质量，但这些跨视角建模问题仍然属于你的方法本身。**

### 10.4 不要把 pretraining mask 当作几何可见性 mask

这是从本文迁移到你项目时，最需要注意的一点。

论文的 mask 是人为构造的训练缺失；你的点云渲染缺失可能来自遮挡、新暴露区域、重建错误或深度不可靠。它们的生成机制完全不同。

因此，“离 mask 边界近，就给更大权重”可以提供设计启发，但不能直接替代几何置信度或可见性建模。对于重拍任务，权重应当由你实际希望相信哪些观测、允许哪些区域变化来决定。

## 总结

**我对 V-JEPA 2.1 的核心评价是：它显著改善了视频预测表征的局部可读性，并用多层自监督缓解了局部结构与全局理解之间的冲突。**

最值得记住的并不是某个最高分，而是两个结论。

**第一个结论：能预测缺失内容，不代表每个位置都学到了适合密集任务使用的特征。**

**第二个结论：增加局部监督会改变表征的取舍，需要同时设计目标层级、监督权重和数据分布。**

对你的研究，这篇论文最有价值的落点是：**先获得更可靠的密集状态表征，再明确训练它如何在几何和目标相机条件下发生变化。**“表征更好”与“跨视角世界预测成立”之间的那一步，正是需要单独建立方法和证据的部分。
